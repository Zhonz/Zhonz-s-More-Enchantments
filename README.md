# ZZ的更多附魔 / Zhonz's More Enchantments

## 模组简介

* 安装此 mod 时不会出现"过于昂贵"

* 此 mod 的增伤效果只参与最后的伤害判定，从而兼容其他 mod 的武器、装备

* 需要 Apothic Attributes（属性模块）作为前置

* 近战武器：剑、斧

* 远程武器：弓弩、三叉戟

## 附魔列表

### 终结 / Finale

* **可附魔**：攻击伤害 ≥ 7 的近战武器

* **效果**：攻击造成原伤害 100000 倍的伤害，随后武器减少等同于伤害量的耐久度

* **稀有度**：宝藏附魔

### 食腐者 / Scavenger

* **可附魔**：头盔

* **效果**：在吃腐肉等可以给玩家造成饥饿 buff 的食物时不再获得饥饿

* **稀有度**：普通附魔

* **灵感**：明日方舟的萨卡兹种族之一食腐者

### 收割 / Harvest

* **可附魔**：近战武器

* **效果**：攻击后被攻击方血量 ≤ 10%/20%/30% 时可以直接击杀对方

* **稀有度**：宝藏附魔，分三级

### 制裁 / Sanction

* **可附魔**：武器

* **效果**：攻击附带被攻击方 1%/2%/3% 最大生命值的真伤

* **稀有度**：宝藏附魔，分三级
