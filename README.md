# Zhonz's More Enchantments

一个为Minecraft添加多种强大自定义附魔的NeoForge模组。

## 兼容性

### 附魔描述 (Enchantment Descriptions)
本模组完全支持 [Enchantment Descriptions](https://www.curseforge.com/minecraft/mc-mods/enchantment-descriptions) mod。当玩家安装了Enchantment Descriptions时，所有附魔都会在工具提示中显示详细描述。

所有附魔描述均使用标准的本地化键格式：`enchantment.zhonz_more_enchantments.<附魔ID>.desc`

## 附魔列表

本模组包含27种自定义附魔，包括：
- 终结 (Finale)
- 食腐者 (Scavenger)
- 收割 (Harvest)
- 制裁 (Sanction)
- 深海的供养 (Deep Sea's Grace)
- 鱼丸 (Fishball)
- 剥壳 (Shell Strip)
- ...等等

完整附魔列表请查看游戏内的附魔书或源代码。

## 安装

1. 安装NeoForge 1.21.1
2. 将模组JAR文件放入`.minecraft/mods`文件夹
3. （可选）安装Enchantment Descriptions以查看附魔描述
